# AGENTS.md

## Contributing

Before creating a branch or opening a PR, read `resources/contribution_guidelines.md` for
branch names, PR titles, and issue links. The repo differs from it in two places: PRs target
`main` (there is no `staging` branch), and PR descriptions use
`.github/PULL_REQUEST_TEMPLATE.md`, the template GitHub loads. Commits are conventional
commits.

## Agent skills

### Issue tracker

GitHub Issues on this repo, read by the course's students. See `docs/agents/issue-tracker.md`.

Single-context: `GLOSSARY.md` at the root, ADRs in `docs/developers/adr/`. See `docs/agents/domain.md`.
